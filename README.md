# Loop & Luxe Test Repo

This repository is the testing and iteration workspace for the Loop & Luxe storefront.

## Purpose
- Build and test new designs, components, and UX ideas here first.
- Keep the live business repository separate from the experimental work.
- Merge only the approved version into the production repo.

## Branch rule
- `development`: active testing branch for all new changes.
- `main`: reserved for stable, approved work that is ready to move forward.

## Working flow
1. Build in `development`.
2. Test the preview on Cloudflare personal account.
3. Review the result.
4. Only then move the approved version to the business repository.

## Project files
- `index.html` — page structure
- `style.css` — visual styling
- `app.js` — storefront logic and product rendering
- `product-images/` — product photography used in testing

## Notes
This repository is intentionally kept clean and focused on testing only.
